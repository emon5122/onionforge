# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, welcome newcomers, and keep discussions focused on the work. Harassment and personal attacks aren't tolerated.

Report unacceptable behavior privately to the maintainer through a [private security advisory](https://github.com/emon5122/onionforge/security/advisories/new) or by contacting [@emon5122](https://github.com/emon5122) on GitHub. All reports are reviewed and handled confidentially.
